Este é o meu **caderno de estudos**: uma base de conhecimento organizada por categorias, com
anotações, comandos e boas práticas de desenvolvimento e infraestrutura.

:::tip[Como navegar]
Use a **barra lateral** para explorar as categorias, a **busca** (<kbd>Ctrl</kbd> + <kbd>K</kbd>) para
encontrar um assunto e o botão de **tema** no topo para alternar entre claro e escuro.
:::
