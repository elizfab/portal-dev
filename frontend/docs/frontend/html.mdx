## Comandos principais

```html title="Exemplo: HTML"
<!doctype html>
<html lang="pt-BR">
  <head>
    <meta charset="utf-8" />
    <title>Minha página</title>
  </head>
  <body>
    <h1>Olá, mundo!</h1>
  </body>
</html>
```
