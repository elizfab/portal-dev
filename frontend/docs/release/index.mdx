- **[Rollout progressivo](./02-estrategias-de-rollout/01-rollout-progressivo.mdx)**: Expansão automática em passos percentuais, guiada por tempo e métricas de saúde.

- **[Rollout sob demanda](./02-estrategias-de-rollout/02-rollout-sob-demanda.mdx)**: Expansão manual, passo a passo, decidida pelo Release Manager.
