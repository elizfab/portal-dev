## Camadas

```text
cmd/                     # entrypoints: API HTTP e função de eventos
internal/
├── domain/              # entidades, tipos e regras puras
├── usecase/             # casos de uso (criação de trens, associação, ações)
├── ports/
│   ├── in/              # interfaces de serviço (o que o sistema oferece)
│   └── out/             # interfaces de repositório e integrações
└── adapters/
    ├── in/http          # handlers REST
    ├── in/event         # roteador de eventos (cron / associação)
    └── out/             # banco, scheduler de eventos, GMUD
```

## Portas principais

| Porta | Tipo | Responsabilidade |
| --- | --- | --- |
| `ReleaseTrainCreationService` | in | Criar os trens do dia |
| `ReleaseAssociationService` | in | Associar releases ao trem |
| `ReleaseTrainBlockRepository.FindByDate` | out | Verificar bloqueio |
| `ReleaseTrainSchedulerRepository.FindActiveByDate` | out | Agendamentos vigentes |
| `ReleaseRepository.FindByStatusAndSchedule` | out | Releases elegíveis |
| `EventPublisher.CreateScheduleRule` | out | Criar disparo único e devolver o ARN |
| `GmudService.CreateGmud` | out | Abrir a mudança (stub enquanto o serviço externo não existe) |

## Decisões

- **UUID v7** gerado nas factories de domínio.
- Banco relacional (PostgreSQL) para FKs e UUID nativo. O template inicial usa MongoDB.
- Deploy em container (Docker multi-stage) e funções orientadas a eventos para os jobs.
- Testes por camada: domínio e casos de uso com mocks das portas.
