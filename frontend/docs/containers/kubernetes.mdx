## Comandos principais

```bash title="Exemplo: Kubernetes"
kubectl get pods -A
kubectl apply -f deployment.yaml
kubectl describe pod minha-app-xyz
kubectl logs -f deploy/minha-app
kubectl rollout undo deploy/minha-app
```
