## Comandos principais

```sql title="Exemplo: Bancos de dados"
CREATE TABLE usuarios (
  id SERIAL PRIMARY KEY,
  nome TEXT NOT NULL,
  criado_em TIMESTAMPTZ DEFAULT now()
);

SELECT nome FROM usuarios WHERE criado_em > now() - INTERVAL '7 days';
```
